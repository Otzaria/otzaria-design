# עיצוב אוצריא

ריפו המקורות של הגרפיקה ש[אוצריא](https://github.com/Otzaria/otzaria) צורכת בבנייה.
כל גרפיקה כאן **נוצרת בקוד** מתוך סקריפט ומקורות שמורים, כך שכל שינוי ניתן לשחזור ולביקורת.

| תיקייה | מה יש בה |
|---|---|
| [`download-assistant/`](download-assistant/) | הגרפיקה של מסייע ההורדות ל-Windows: אנימציית הספר הנפתח, בלוק הכותרת בעברית ובאנגלית, וערכת הממשק |

## איך הריפו הראשי צורך את זה

הריפו הראשי אינו מריץ את הסקריפטים ואינו שומר תמונות בגיט. כל פרויקט כאן מתפרסם כ-Release עם
zip של הפלט, והריפו הראשי נועץ גרסה אחת שלו (גרסה + SHA-256) ומוריד אותה לפני הבנייה.
פרטים ב-README של כל תיקייה.

## רישיון

הקוד בריפו הזה תחת הרישיון של אוצריא (`LICENSE`). למקורות שבתוך כל תיקייה (גופנים, לוגו) יש
רישיונות משלהם, המפורטים ב-`sources/LICENSES.md` שבה.
